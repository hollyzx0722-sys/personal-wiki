CPU HT 与 Turbo

HT 通过一个物理核心提供两个逻辑线程，Turbo 在功耗和温度允许时动态提高核心频率；两者分别改善并发吞吐和突发性能。

概念工程当代已整理
一句话概述
HT 是“一个核心处理两个线程”，Turbo 是“核心在条件允许时跑得更快”。

核心信息

HT 全称Hyper-Threading，超线程技术
Turbo 全称Intel Turbo Boost，睿频加速
HT 主要收益提高并发吞吐，不等于核心数翻倍
Turbo 主要收益提高单线程和短时突发性能

关键事实 / 关键故事

HT 如何计算
双路 16 核 CPU 共 32 个物理核心，开启 HT 后通常显示 64 个逻辑处理器；两个线程会共享同一个物理核心的执行资源和缓存。
Turbo 如何工作
基础频率是长期设计基线，最高睿频通常只在少量核心、温度和功耗条件允许时出现；全核负载下实际频率一般低于单核峰值。
如何查看
Linux 可用 lscpu 查看 CPU、Core(s) per socket、Socket(s) 和 Thread(s) per core；BIOS、电源模式和散热会影响 Turbo。

争议与辨析

HT 通常提升吞吐但不会带来 100% 性能增长；对极致低延迟、授权按逻辑 CPU 计费或安全隔离要求高的场景，可能需要关闭 HT。Turbo 也不是所有核心长期保持最高频率。
