Ontology API 数据类型

Ontology API 通常把底层表或数据集映射成业务对象、属性、关系和动作，而不是简单把每一张物理表原样暴露出来。

一句话概述
Ontology API 的核心是把“表数据”提升成可理解、可关联、可操作的业务语义模型。

核心信息

Object Type业务对象类型，类似实体主表
Property对象字段，如名称、状态、金额
Link Type对象之间的关系，类似外键但带业务语义
Action Type受控写操作，如创建、审批、变更状态

关键事实 / 关键故事

对象不等于物理表
一个对象类型可能来自一张表、多张表关联、数据集、流式数据或计算结果。
属性有多种数据类型
常见有字符串、整数、浮点数、金额、布尔值、日期时间、枚举、数组、附件和空间数据。
关系是 API 的重要价值
服务器可以关联应用，客户可以关联订单，调用方通过业务关系导航数据，不必每次手写底层连接。
接口与函数
Interface 可定义多种对象共有的字段；Query / Function 用于查询、计算或封装可复用逻辑。

关系网

Ontology 层数据库类比例子
Object Type实体表 / 主表客户、订单、服务器
Property字段状态、金额、CPU 核数
Link Type外键 / 关系表客户拥有订单
Action Type写入接口 / 事务创建订单、提交审批

争议与辨析

“Ontology API”不是唯一标准术语。不同平台可能使用 Object Type、Entity、Thing、Relation、Action 等不同命名；精确字段和返回结构必须以对应产品 API 文档为准。
